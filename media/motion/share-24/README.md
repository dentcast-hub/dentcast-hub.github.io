# Share Hub 24 — motion teaser

22-second scored portrait video, 720 × 1280, 24 fps, H.264 / yuv420p.

- `share-24-motion.mp4`: ready to download and edit into a Reel.
- `share-24-motion.html`: self-contained editable animation; embedded existing DentCast Vazirmatn font. Open in a browser; replay button restarts playback. `?render` disables autoplay and exposes `window.render(seconds)` for deterministic capture.
- `render.cjs`: deterministic SVG frame renderer. Requires Node.js, `sharp`, FFmpeg, and Vazirmatn installed in fontconfig. Run `npm install --no-save sharp` in a separate temporary dependency directory, then `node render.cjs` with that directory on `NODE_PATH`. Font source: `/fonts/Vazirmatn-Bold.woff2` in this repository (convert to TTF with fontTools/Brotli when needed).

Source article: https://dentcast.org/sharehub/share-24.html

## Sequence

0–5 s: dentist seated in clinic; patient arrives; short upper centrals appear in a schematic.
5–10 s: dentist considers where to begin and what treatment is appropriate.
10–14 s: DentCast phone card with the exact article title and author; all body copy is replaced by unreadable placeholder bars that scroll upward. This is a stylized article card, not a screenshot of the live page.
14–18.5 s: light bulb appears; dentist turns back toward patient to continue assessment.
18.5–22 s: article title and DentCast call to action.

No diagnosis, cause, or treatment choice is revealed. No clinical before/after result is shown. No changes to the source article, site navigation, content indexes, or publishing records.

## Verification

Rendered all 528 frames from the same scene timing function used by the HTML. Inspected clinic, thought, phone, light bulb and closing frames for Persian shaping and layout. Verified MP4 duration, frame count, dimensions, codec and pixel format with ffprobe. Includes an original procedural electric-guitar-style stereo score, generated by `music.py` without samples.

## Rebuild soundtrack

Requires Python numpy and scipy. Run `python3 music.py`, render video with `node render.cjs /tmp/share24-silent.mp4`, then mux:

```sh
ffmpeg -y -i /tmp/share24-silent.mp4 -i music.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart share-24-motion.mp4
```

The HTML preview is silent. The MP4 includes the score. Generated WAV is temporary and is not committed.

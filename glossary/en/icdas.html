ICDAS

Definition

ICDAS (International Caries Detection and Assessment System) is a standardized system for the visual detection and recording of caries that expresses the severity of a lesion on each tooth surface with a code from 0 to 6. Code 0 means a sound surface. Codes 1 and 2 are visual changes in enamel without surface breakdown: code 1 is seen only after prolonged air-drying, and code 2 is distinct on a wet surface as well. Code 3 is localized enamel breakdown without visible dentin, and code 4 is a dark shadow seen from the dentin beneath the enamel. Code 5 is a distinct cavity with visible dentin, and code 6 is an extensive cavity involving more than half of the surface.

The examination is performed on a clean tooth, first wet and then after air-drying. The current version of the system is ICDAS II, and surfaces with a restoration or sealant are recorded with a two-digit code in which the first digit indicates the restoration status and the second the caries code.

Concept Boundary & Misconceptions

The most common misconception is that an ICDAS code is a treatment instruction. The system only states how far a lesion has visibly progressed and says nothing about whether it is active or arrested. Two lesions with the same code can behave entirely differently: one progressing, the other arrested for years. Assessment of lesion activity and patient risk is a separate stage that was added to ICDAS within the ICCMS framework.

The second misconception is that the codes are equal steps of lesion depth. Code 4 has no open cavity and looks sounder than code 3, but the dark shadow shows that dentin is involved and the lesion is usually deeper. For this reason the visual code does not replace radiography and does not by itself determine the true depth of the lesion.

The third point concerns the examination method. ICDAS is a visual system, and a sharp explorer has no place in it. Pressing an explorer into an early lesion can break the enamel surface and turn a reversible lesion into a cavity. If an instrument is used at all, it is a ball-ended probe, used only to gently feel the surface. Without cleaning and drying the tooth, distinguishing code 1 from code 2 is practically impossible.

Role in Clinical Decision-Making

The main value of ICDAS is that it records early lesions before cavitation, that is, at a time when progression can still be stopped with non-invasive measures such as plaque control, fluoride and sealants. For codes 1 and 2 the principle is non-invasive treatment and monitoring. For codes 3 and 4 the decision depends on lesion activity, its depth on the radiograph and the patient's risk. For codes 5 and 6 restorative treatment is usually required.

The second use is monitoring over time. When each surface has been recorded with a specific code, the next visit can show whether the lesion has remained stable or progressed, and this comparison becomes the basis for continuing to monitor or starting an intervention. This standardized recording also creates a common language among dentists and among studies. The ICDAS code defines the severity of a lesion, but the treatment decision comes from putting severity, activity and patient risk together.
